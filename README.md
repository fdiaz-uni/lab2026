# Lab 2026 - Tecnologías Web

Bienvenido al repositorio con los ejemplos vistos en el laboratorio de la asignatura **Tecnologías Web** (Curso 2026-27). Aquí encontrarás todo el material de apoyo, plantillas y soluciones de las sesiones del curso.

---

## Instrucciones para Alumnos

### 1. Primera descarga (Clonar el repositorio)
Si es la primera vez que vas a trabajar con este material, abre la terminal de tu máquina Linux, muevete a la carpeta donde quieras guardar la asignatura los ejemplos (se recomienda ~/public_html si tienes configurado los sitios personales de usuario) y ejecuta:

```bash
git clone https://github.com/fdiaz-uni/lab2026.git
```
*Esto creará una carpeta llamada `lab2026` con todos los archivos disponibles hasta el momento.*

### 2. Actualizar el material (Nuevas sesiones)
A lo largo del curso se irán añadiendo nuevas sesiones y ejercicios. **No vuelvas a clonar el repositorio**. Para descargar el contenido nuevo, entra a la carpeta desde tu terminal y descarga las actualizaciones:

```bash
cd lab2026
git pull
```
*Se recomienda ejecutar `git pull` al inicio de cada sesión de laboratorio para asegurarte de tener la última versión.*
